# Roadmap

These are planned improvements, not implemented features or delivery commitments.

- **Shared transport:** bring extended retries, cache controls, and source diagnostics into the installed package without requiring the skill layout.
- **Unified evidence model:** replace legacy property lists with page/context records and explicit review state across both CLIs.
- **Search evaluation:** introduce a curated, versioned query set with human relevance judgments before claiming retrieval-quality gains.
- **Provider health checks:** keep live probes separate from deterministic unit tests and expose provider-specific changes clearly.
- **Packaging:** explore an optional install extra for the extended chemistry workflow while preserving a small base dependency set.

The project is CLI-only. A hosted application or web UI is outside the current scope.
